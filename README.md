# 天依浏览器 (Tianyi Browser)

🎤 洛天依主题的轻量级浏览器

![Version](https://img.shields.io/badge/version-1.0.0--beta-blue?color=66ccff)
![Electron](https://img.shields.io/badge/Electron-31-4ab8f0)
![Platform](https://img.shields.io/badge/platform-Windows-66ccff)

## ✨ 功能特性

- 🌐 **多标签浏览** — 类似 Chrome 的标签页管理
- 🔍 **多搜索引擎切换** — 支持百度、Google、Bing、搜狗、哔哩哔哩搜索
- ⭐ **书签管理** — 收藏常用网站，右键删除
- ⬇️ **下载管理** — 内置下载进度面板
- 🎨 **天依蓝主题** — 主色调 #66ccff，洛天依风格 UI
- 🖼️ **洛天依壁纸新标签页** — 打开新标签就能看到依酱

## 🛠️ 技术栈

- [Electron 31](https://www.electronjs.org/) — 跨平台桌面框架
- 原生 HTML/CSS/JavaScript — 无框架依赖，轻量快速
- electron-builder — MSI 安装包打包

## 📥 下载安装

前往 [Releases](https://github.com/your-repo/tianyi-browser/releases) 下载最新版 MSI 安装包，双击即可安装。

## 🚀 本地开发

```bash
# 安装依赖
npm install

# 启动开发模式
npm start

# 打包 MSI
npm run build
```
